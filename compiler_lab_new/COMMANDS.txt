===================================================================
                 COMMANDS FOR LAB EXAMINATION
===================================================================

1. RUN INDIVIDUAL PARTS:
   Part (a): lex part_a.l && gcc lex.yy.c -o part_a && ./part_a < exam_input.txt
   Part (b): yacc -d part_b.y && lex part_b.l && gcc y.tab.c lex.yy.c -o part_b && ./part_b < exam_input.txt
   Part (c): yacc -d part_c.y && lex part_c.l && gcc y.tab.c lex.yy.c -o part_c && ./part_c < exam_input.txt > tac.txt && cat tac.txt
   Part (d): gcc part_d.c -o part_d && ./part_d < tac.txt > opt_tac.txt && cat opt_tac.txt
   Part (e): gcc part_e.c -o part_e && ./part_e < opt_tac.txt

2. RUN INTEGRATED COMPILER (PART F):
   gcc part_f.c -o part_f
   ./part_f exam_input.txt
   ./part_f input.txt
